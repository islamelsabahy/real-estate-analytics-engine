# Sales Funnel Model

Illustrative stages:

```text
Lead
→ Qualified
→ Opportunity
→ Reservation
→ Contract
```

## Metrics

- Lead-to-Qualified %
- Qualified-to-Opportunity %
- Opportunity-to-Reservation %
- Reservation-to-Contract %
- Overall Lead-to-Contract %
- Median days between stages
- Stage drop-off
